## Background and Terminology

The arithmetic logic unit (ALU) is what allows our CPU (central *processing* unit) to actually do any processing. The SAP-1's ALU can only perform addition and subtraction on two 8-bit numbers. While it seems rudimentary, Ben Eater's design is Turing-complete; with only two operations, you can use software to develop any other operation (multiplication, division, *etc.*). 

In the F8-BB ALU, the hardware is optimized to allow for additional functionality and flexibility. In particular, addition, subtraction, and logic operations can be performed using the 74LS382 IC. Fadil-1's design also features logical bit-shift operations, which can be used to optimize multiplication and division.

My ALU design follows almost exactly from that of the F8-BB.
